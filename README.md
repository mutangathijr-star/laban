# Open Me 👀 | Laban's Hidden Message App

An interactive, synthwave-styled secret message web application for Laban confessing his love, set to the vibe of **"Blinding Lights" by The Weeknd**.

## 🌟 Features
- **Neon Synthwave Aesthetic**: Glassmorphism UI, floating glowing particles, and pulsing neon accents.
- **Background Music Player**: Embedded audio controller playing *Blinding Lights* by The Weeknd (or custom audio).
- **Interactive Confession Arc**:
  - **Landing Page**: Shows `photo.jpg` (or interactive drag-and-drop photo uploader).
  - **Honest Intro**: Acknowledges Laban's past mistakes while expressing sincere feelings.
  - **Secret Message Loop**: 10 sequential secret messages revealing Laban's thoughts, memories, and affection.
  - **Interactive Quiz**: Lighthearted banter ("Who has Laban completely wrapped around their finger?").
  - **Final Confession**: Heartfelt love confession & aesthetic closing letter.

## 📸 Adding Your Photo
1. Simply place your image named `photo.jpg` inside this directory (`C:\Users\USER\.gemini\antigravity\scratch\open-me-laban\ photo.jpg`).
2. Alternatively, you can click on the photo avatar on the landing screen to upload/select any picture directly from your computer!

## 🚀 How to Run
Double-click `index.html` or open it in any web browser!
